# CVMatch AI — Otimize seu currículo para cada vaga

**CVMatch AI** é uma aplicação web criada para comparar um currículo com uma descrição de vaga, identificar correspondências e lacunas de palavras-chave e gerar uma versão do currículo mais adequada para sistemas ATS.

> **Apresentação melhor. Experiência verdadeira.**

## 🎯 Problema

Muitas pessoas candidatam-se a vagas sem saber se o currículo está suficientemente alinhado à descrição da oportunidade.

Além disso, sistemas de recrutamento que utilizam ATS podem analisar termos, competências e informações presentes no currículo antes da avaliação humana.

O CVMatch AI foi criado para facilitar essa análise e ajudar o candidato a melhorar a apresentação das informações que ele já possui.

## 💡 Solução

A aplicação permite:

- inserir uma descrição de vaga;
- inserir o currículo;
- analisar a correspondência textual entre os dois conteúdos;
- visualizar um percentual estimado de match;
- identificar palavras-chave encontradas;
- identificar palavras-chave relevantes que podem estar faltando;
- receber sugestões de melhoria;
- gerar uma versão organizada e ATS-friendly do currículo;
- copiar o currículo gerado;
- exportar o currículo em PDF.

### Regra principal

O CVMatch AI **não deve inventar experiências, empresas, cargos, competências, certificações ou resultados**.

As sugestões servem para melhorar a apresentação das informações verdadeiras do candidato.
